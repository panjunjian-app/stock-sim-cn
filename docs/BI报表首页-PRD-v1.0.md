# 「炒炒乐」BI 报表首页增量方案（简单 PRD）

> 版本：v1.1 ｜ 日期：2026-11-04 ｜ 作者：许清楚（PM） ｜ 状态：✅ 已对齐（2026-11-04 用户确认）

## 一、项目信息

- **Language**: 简体中文
- **Programming Language**: 沿用现有栈（React 18 + TypeScript + MUI + Cloudflare Pages/Functions + D1），新增图表库建议 **Recharts**（MIT 开源免费，符合零成本红线；与 klinecharts/SVG 并存，互不影响）
- **Project Name**: `ccle-bi-dashboard`
- **原始需求复述**: 登录后首页改为 BI 报表页，支持选择时间段（默认近 7 天），展示收益情况、持仓成本等 BI 分析图表，让玩家了解指定时间内的模拟投资表现。方案对齐后再开发。

## 二、产品目标与用户故事

**目标**
1. 让玩家在一个页面内看清指定时段的收益全貌（资产曲线、盈亏、回撤、胜率）。
2. 通过持仓与交易行为分析，帮助玩家发现亏损/盈利来源，提升复盘能力与留存。
3. 零成本落地：全部指标由现有 D1 表 + 新增 1 张每日快照表计算，不引入付费依赖。

**用户故事**
- As a 玩家, I want 登录即看到近 7 天资产曲线与总收益率, so that 我能快速知道自己最近玩得怎么样。
- As a 玩家, I want 查看单股盈亏贡献排行和持仓成本 vs 现价对比, so that 我知道哪只股票赚/亏得最多、该不该止损。
- As a 拥有多个账户的玩家, I want 按单账户或全部账户汇总查看 BI, so that 我能分别复盘也能看整体表现。

## 三、BI 图表清单（核心）

> 口径说明：模拟盘无出入金，收益率直接以总资产变动计算。**总资产 = cash_available + Σ(持仓股数 × 现价)**。全部账户汇总时各账户资产直接加总。

### A. 收益总览（P0）

| # | 图表 | 类型 | 核心指标口径 | 交互 |
|---|------|------|------|------|
| A1 | 总资产 | KPI 卡片 | cash + 持仓市值（现价实时） | 点击跳转账户列表；多账户汇总模式显示各账户分布 tooltip |
| A2 | 区间收益率 | KPI 卡片 | （期末总资产 − 期初总资产）/ 期初总资产 | 红涨绿跌着色；hover 显示期初/期末资产绝对值 |
| A3 | 区间盈亏 & 当日盈亏 | KPI 卡片×2 | 区间盈亏 = 期末资产 − 期初资产；当日盈亏 = 今日资产 − 昨日快照资产 | 着色；当日盈亏标注"截至最新行情" |
| A4 | 已实现盈亏 / 浮动盈亏 | KPI 卡片×2 | 已实现 = 区间内卖出成交的（卖出价 − 加权成本价）× 数量 − 费用（由 trades 回算）；浮动 = Σ(现价 − 成本价) × 持仓数（仅当前在持部分） | hover 展开明细表 |

### B. 净值与收益（P0）

| # | 图表 | 类型 | 核心指标口径 | 交互 |
|---|------|------|------|------|
| B1 | 资产净值曲线 | 折线图（面积） | 以期初资产归一为 1.0 的净值 = 每日总资产 / 期初总资产（数据源：daily_snapshots） | 支持缩放/十字准线；hover 显示当日资产、当日盈亏；切换"金额/净值"两种视图 |
| B2 | 每日盈亏 | 柱状图 | 当日总资产 − 前一日总资产，正负着色 | hover 显示当日明细；点击联动到当日成交记录 |
| B3 | 最大回撤 | KPI 卡片 + 曲线标注 | max(1 − 当日净值 / 历史区间峰值净值)，区间内计算 | 卡片显示回撤幅度与发生日期；净值曲线上标注回撤区间阴影 |

### C. 持仓分析（P0）

| # | 图表 | 类型 | 核心指标口径 | 交互 |
|---|------|------|------|------|
| C1 | 持仓成本 vs 现价对比 | 表格 + 横向条形（双条对比） | 每持仓：加权成本价 = Σ买入金额/Σ买入股数（trades 回算）；盈亏% = (现价 − 成本)/成本 | 按盈亏% 排序；点击行跳转个股 K 线 |
| C2 | 持仓市值分布 | 环形图 | 各持仓市值 / 总持仓市值；含"现金"扇区则更完整（建议含现金） | hover 显示占比与市值；点击高亮 |
| C3 | 持仓集中度 | KPI 卡片 + TOP5 条形 | 集中度 = TOP5 持仓市值 / 总资产；单一持仓上限警示（>50% 标红） | hover 显示各持仓占比 |

### D. 交易行为分析（P1）

| # | 图表 | 类型 | 核心指标口径 | 交互 |
|---|------|------|------|------|
| D1 | 交易频次 | 柱状图（按日） | 区间内成交笔数 / 区间天数；按日展示笔数 | hover 显示当日买/卖笔数与金额 |
| D2 | 胜率 | KPI 卡片 + 环形图 | 胜率 = 已实现盈利卖出笔数 / 全部卖出笔数（按笔，trades 卖出方向回算） | hover 显示盈/亏/平笔数 |
| D3 | 盈亏比 | KPI 卡片 | 平均单笔盈利额 / 平均单笔亏损额绝对值 | 与胜率同卡片区域展示，附简单释义 |
| D4 | 买卖方向与资金流 | 堆叠柱状图（按日） | 每日买入金额 vs 卖出金额 | hover 显示净流入 |

### E. 个股盈亏归因（P0 核心价值区）

| # | 图表 | 类型 | 核心指标口径 | 交互 |
|---|------|------|------|------|
| E1 | 单股盈亏贡献 TOP10 | 横向条形图（正负双向） | 单股区间盈亏 = 已实现盈亏(该股卖出) + 浮动盈亏(在持部分)，按贡献降序取前 5 / 后 5 | 正负着色；点击跳转个股页 |
| E2 | 个股盈亏占比 | 环形图 | 各股盈亏贡献 / 区间总盈亏（剔除盈利与亏损对冲展示可切换） | hover 显示金额与占比 |

**优先级取舍说明**：行业分布图（P2）——现有表无行业字段，需引入免费股票行业映射数据，首版不做；净值基准对比（如对比沪深300，P2）——需保存指数日线，后续迭代；D 组交易行为分析为 P1。

## 四、时间范围选择器

- **选项**：近 7 天（默认）/ 近 30 天 / 近 90 天 / 今年至今 / 全部
- **实现**：页面级全局状态（URL query 参数 `?range=7d&acct=all`），所有图表组件订阅同一状态，切换时仅 Functions 层重新聚合，前端不重复拉取明细
- **联动规则**：
  - B1/B2（曲线/日柱）：按所选范围取 daily_snapshots 序列，"全部"时 D1 按月聚合防止点过多
  - A2/A3、E1/E2：按范围首尾快照计算区间值
  - D1–D4：按范围过滤 trades
  - A1、C1–C3（当前持仓类）：与时间无关，恒显示实时快照，但 C1 成本可切换"当前成本 / 区间期初成本"
- 切换范围后各图表带 loading 骨架屏，接口返回 < 1s（D1 聚合 + 索引）

## 五、页面布局与导航

- **登录后首页 → BI 报表页**，布局（自上而下）：
  1. 顶部工具栏：账户维度选择器 + 时间范围选择器（Segmented Control）
  2. KPI 卡片区（两行，响应式栅格）：A1–A4、B3、D2/D3（P1 后补）
  3. 资产净值曲线（全宽，主图）+ 每日盈亏（并列或下方）
  4. 两栏区：持仓分析（C1–C3）｜个股盈亏归因（E1–E2）
  5. 交易行为区（P1 迭代追加）
- **账户维度建议**：默认**全部账户汇总**（玩家最关心整体表现），支持下拉切换单账户；汇总视图在 KPI 上附加"最佳/最差账户"小字提示，增强多账户玩法趣味性
- **导航调整**：顶部导航新增"分析报告"（首页/默认）与"我的账户"两个入口，原账户列表页完整保留（含快捷下单、创建账户），路径如 `/dashboard` 与 `/accounts`；个股页、自选等入口不变

## 六、数据可行性说明（架构师重点）

**现有表可直接计算**：
- 当前总资产、浮动盈亏、持仓分布、集中度（positions + 行情现价）
- 已实现盈亏、胜率、盈亏比、单股归因、交易频次（trades 回算：卖出时按加权成本，需在卖出成交时或查询时回放买入 FIFO/加权）

**新增必需：`daily_snapshots` 快照表**（否则无法画历史曲线、算回撤）：
```
daily_snapshots(user_id, account_id, date, total_assets, cash, market_value, day_pnl, PRIMARY KEY(user_id, account_id, date))
```
- **采集方案（零成本）**：复用现有行情轮询——每次行情刷新时对登录用户在持账户 upsert 当日快照（最后写入者生效，无需定时器/付费 Cron）；无成交无持仓的日子也 upsert（资产=现金，曲线连续）
- **历史缺失日回放补齐**：首次进入 BI 时若快照覆盖不足，按 trades 按日回放（逐日重算当日收盘时的持仓市值 + 现金），一次性补齐写入；补齐后标记，避免重复计算。注意补齐需历史收盘价——可复用 klinecharts 行情源的日线数据（免费）
- **T+1 边界**：快照以交易日为准（非自然日），周末节假日不产生快照点，曲线按交易日连续展示

## 八、用户已确认的决策（2026-11-04）

1. **默认账户维度**：✅ 默认「全部账户汇总」，可切换查看单账户。
2. **图表库选型**：✅ Recharts（MIT 免费开源），与 klinecharts/SVG 并存，不替换现有 K 线。
3. **首页形态**：✅ 纯分析页 + 显著「进入账户」按钮，不放快捷下单入口。
4. **收益率口径**：✅ 资产变动法：(期末总资产 − 期初总资产) / 期初总资产，不支持中途追加资金。
5. **历史数据范围**：✅ 上线前历史成交按 trades + 免费日线收盘价回放补齐快照。
